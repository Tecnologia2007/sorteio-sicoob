# Sorteio Sicoob 🎲

Aplicação web de sorteio rápido e interativo em tela única, desenvolvida com o **Sicoob Design System**.

## 🚀 Funcionalidades
- **Gestão de Participantes**: Cadastro com validação (mínimo de 2 caracteres, bloqueio de nomes duplicados) e remoção individual.
- **Sorteio Interativo**: Animação de tambor giratório e revelação do vencedor com efeito sonoro visual.
- **Histórico**: Registro automático de todos os sorteios realizados na sessão.
- **Limpeza Rápida**: Opção de resetar participantes com confirmação.

## 🎨 Design System
- **Identidade Sicoob**: Persian Green (`#00A88F`), Cyprus (`#003641`) e Lima (`#A6D900`).
- **Tipografia**: Manrope.
- **Formas**: Cantos arredondados, elevações suaves e design responsivo (desktop e mobile).

## 💻 Como Executar
Basta abrir o arquivo `index.html` em qualquer navegador web moderno. Não requer dependências externas nem build.
